## 📋 Document Scope

**What belongs in this directory**:
- Historical session summaries (dated)
- Implementation notes from specific fixes
- Deprecated documentation
- Temporary docs no longer actively used

**What does NOT belong here**:
- ❌ Active documentation (→ belongs in appropriate category)
- ❌ Architecture or design docs (→ belongs in 02-architecture/)
- ❌ Current guides (→ belongs in 05-guides/)

---

## Overview

This directory contains historical and session-specific documentation that is preserved for reference but not actively maintained.

## Directories

### [sessions/](sessions/)
Session summaries from development sessions:
- Dated session notes (YYYY-MM-DD format)
- What was accomplished
- Decisions made

### [implementation-notes/](implementation-notes/)
Implementation notes from specific fixes and features:
- Startup fixes
- OAuth implementation
- Bug fix summaries

---

## Archive Policy

Documents are archived here when:
- Session is complete (session summaries)
- Feature is implemented (implementation notes)
- Documentation is superseded (deprecated docs)
- Content is historical reference only
