# Component Documentation

This directory contains detailed documentation for each component in the TransparentAiAgent system.

## Organization

Components are organized by architectural layer:

- **core/** - Core domain and application logic components
- **llm/** - LLM provider integration components
- **mcp/** - MCP protocol and tool system components
- **infrastructure/** - Cross-cutting infrastructure components
- **ui/** - Blazor UI components and state management

## Documentation Status

**Phase**: Component structure defined

Component detail documentation will be created during implementation as each component is developed following TDD approach.

## Component Categories

### Core Components
Application-level orchestration and business logic.

### LLM Integration
Abstractions and implementations for LLM providers.

### MCP Integration
Model Context Protocol client and tool system.

### Infrastructure
Configuration, authentication, transparency, and other cross-cutting concerns.

### UI Components
Blazor components and presentation layer.

## Reading Component Documentation

Each component doc (when created) will include:
- **Purpose**: What the component does
- **Responsibilities**: Specific responsibilities
- **Interfaces**: Public contracts
- **Dependencies**: What it depends on
- **Implementation Notes**: Key design decisions
- **Testing Strategy**: How to test it
