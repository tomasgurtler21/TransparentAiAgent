## 📋 Document Scope

**What belongs in this directory**:
- System architecture overviews and diagrams
- Clean Architecture layer descriptions
- Data flow and component interactions
- Design patterns used in the system
- Design decisions with rationale (DD-XXX log)

**What does NOT belong here**:
- ❌ Component-specific implementation details (→ belongs in 04-components/)
- ❌ Cross-cutting concepts (→ belongs in 03-concepts/)
- ❌ Code examples (→ belongs in components or guides)
- ❌ How-to guides (→ belongs in 05-guides/)
